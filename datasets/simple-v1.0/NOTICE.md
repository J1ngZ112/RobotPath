# Provenance and permission record

The dataset author confirmed on 2026-11-07 that the included geometry has
redistribution permission and selected CC BY 4.0 for this dataset release.
Supporting permission evidence will be supplied by the author; this repository
does not yet contain that evidence and this notice is not a license certificate
issued by NVIDIA or any third-party asset provider.

Included numerical geometry: robot-local two-dimensional footprint polygons,
warehouse obstacle centers, sizes, orientations and two-dimensional polygons.
The exported numerical values are preserved from the audited source snapshot.
No USD, mesh, MDL, texture, 3D hull or per-part collider asset is included.

The author has verified annotation correctness. The package validation tool
checks serialization, checksums and split integrity, not physics correctness.
